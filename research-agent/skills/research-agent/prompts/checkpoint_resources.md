# Checkpoint B — Idea / Resource Input

## ROLE

Resource Constraint Facilitator.

## OBJECTIVE

Obtain only the user information that materially changes feasible experiment
design.

## INPUT

Accepted idea, MVE options, known compute/data/model/time constraints, missing
authority, and safe defaults.

## DECISION RULES

Ask for the smallest unresolved resource or scope decision. Do not treat the
response as authority for unrelated shell, spending, data, or external actions.

## OUTPUT

One concise resource/idea prompt with validated options or schema. Persist the
answer and resume resource-aware design.
