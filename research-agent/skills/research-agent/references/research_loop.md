# Research Loop

`Literature → Limitation → Cross-paper Pattern → Root Cause → GAP → Search Again
→ Refine GAP`

## Literature landscape

Search complementary axes: canonical work, latest work, strong and open-source
baselines, failure analyses, adjacent mechanisms, and possible novelty overlap.
Use available search tools rather than a hard-coded provider. Prefer primary
paper and publisher/repository records.

Retrieval is not verification. Keep candidate, verified metadata, acquired
content, and rejected records distinct. Preserve provider disagreements and
preprint/conference/journal versions under one work family without treating them
as independent papers. Metadata agreement does not prove extraction correctness.

Use only content actually obtained at inference time. Bind extracted statements
to the paper version, source layer, artifact, and structured locator when known.
Never estimate missing pages. Keep author-stated limitations, direct results, and
agent-inferred limitations epistemically distinct. Abstract-only evidence cannot
support detailed method, ablation, failure-mode, or limitation claims.

## GAP construction

Build GAPs from recurring observations across papers, not one paper's future-work
sentence. Preserve contradictory evidence and competing root causes. A GAP must
state the observed pattern, affected settings, plausible root cause, missing
capability, simplest alternative explanation, and a minimum discriminative
experiment with support and falsification outcomes.

Search again when evidence coverage, identity, version consistency, extraction
quality, or novelty scope is insufficient. Shortlist only 3–5 non-duplicate GAPs
whose evidence reliability, novelty, feasibility, research value, and risk are
reported separately. Any negative novelty conclusion is bounded to the searched
corpus.
