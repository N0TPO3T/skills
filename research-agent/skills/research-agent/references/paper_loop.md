# Paper Loop

`Evidence → Claims → Paper → Reviewer → Missing Evidence → Experiment → Paper
Revision`

Writing is not the workflow endpoint. Build a `PaperPackage` from typed state,
verified literature, evidence, and the experiment ledger rather than chat history
or raw logs. It must cover the problem, GAP, root cause, hypothesis, method,
contributions, related-work positioning, setup, results, ablations, analyses,
failure cases, limitations, claim-evidence matrix, tables, figure requirements,
citations, reproduction instructions, and a do-not-claim list.

Every reported experimental number must resolve to an experiment ID and runner
artifact. Every literature claim must resolve to verified paper evidence. Use no
stronger language than each claim's evidence level permits; preserve uncertainty,
negative results, and scope boundaries.

Audit readiness before drafting. Paper review checks missing baselines,
ablations, unfair comparisons, unresolved confounders, weak evidence, novelty
overreach, reproducibility, and unsupported generalization. Blocking evidence
gaps return to the experiment loop; prose-only issues return to paper assembly.
Complete only when blocking issues are resolved or explicitly bounded.

The final research report records the initial direction, landscape, candidate and
selected GAPs, hypothesis evolution, idea review, resources, experiment plan,
baseline reproduction, complete experiment and failure history, diagnoses,
pivots, final method, results, ablations, failure cases, remaining uncertainty,
reproduction instructions, and future work.
